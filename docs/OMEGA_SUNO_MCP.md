# M0: Omega -> Official Suno MCP connection proof

Endpoint: **https://api.suno.com/mcp** (Suno documentation: https://help.suno.com/en/articles/14551425 and https://help.suno.com/en/articles/14486145).

M0 is **not yet verified**. We have verified provider documentation and ChatGPT integration capability, not connection by an Omega runtime.

## Operator checklist

- [ ] Identify installed Omega version and its supported remote HTTP MCP/OAuth client.
- [ ] Connect to Suno's official server through supported authorization (never commit tokens/cookies).
- [ ] Discover server tools; record observed names and grants.
- [ ] Make read-only account/usage or library request; retain sanitized evidence.
- [ ] With explicit user approval and credit budget, generate one short *original* instrumental.
- [ ] Retrieve job/status/clip ID and finished/playable result; handle asynchronous completion.
- [ ] Request supported read-only audio analysis, or document unavailability.
- [ ] Publish a reproducible redacted M0 report with versions, blockers, observed capability, costs and result.

**Pass condition:** genuine Omega-originated authenticated MCP operations and a completed authorized generation, not a ChatGPT-only demonstration. If OAuth is unsupported, record the blocker and do not claim a pass.

No unofficial wrappers, credential sharing, unauthorized billing, publishing or third-party remixes. Provider grants and model choices can change; inspect before selecting optional controls. Later MIDI/stem/analysis tests are distinct milestones.

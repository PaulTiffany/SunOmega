# Roadmap

## M0 — Omega operates Suno MCP (first gate)
Use an existing Omega and the official remote Suno MCP, with its own authentication. Discover tools, verify read-only operations and (on explicit approval) create a short track. Record exact evidence; do not presume OmegaHive access. See OMEGA_SUNO_MCP.md.

## M1 — shared agent-first knowledge (parallel work)
Build source-attributed, versioned JSON records, a deterministic MeTTa/Hyperon AtomSpace projection, search and validation. Include official Suno capabilities and cautiously summarized Reddit v6 guidance. Keep public production expertise separate from private taste data.

## M2 — MIDI and prompted generation
Agents construct original MIDI using conventional composition tools. Test how the official MIDI conditioning follows notes and rhythm; record model, grants, costs, errors and measured fidelity.

## M3 — music-production experiments
A/B prompt structures, genre/feel, vocal prosody, builds, instrumentation, tempo and reference influence. Store positive and negative results with provenance and links to owned outputs.

## M4 — continuous mix
Use Suno output audio/analysis/stems, local beat-aware playback and prepared bridges. Generation prepares the next song while a current song plays. Playback must not depend on instantaneous Suno generation.

## M5 — OmegaDJ feedback adapters
Add optional game-state/relational and consented aggregate biofeedback, plus private opt-in preference profiles. Do not claim an objective mood sensor.

**Out of scope:** novel origination/continual-learning research, unofficial Suno endpoints, sharing user tokens, rebuilding Omega, biometric surveillance, or production reliability claims before tests.
